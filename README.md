## lesson2 Pythonプログラミングの基礎

### 01 変数と計算
* **`lesson201_1-5.py`**: 四則演算
* **`lesson201_7-8.py`**: 演算子の優先順位
* **`lesson201_10-12.py`**: 文字列の連結
* **`lesson201_14-17.py`**: 型を調べる `type` 関数
* **`lesson201_18-20.py`**: `int` と `float` の数値計算
* **`lesson201_21-26.py`**: 文字列を数値に変換
* **`lesson201_28-30.py`**: `print` 関数
* **`lesson201_31-32.py`**: フォーマット文字列
* **`lesson201_33-34.py`**: 変数を使う
* **`lesson201_37-40.py`**: コメントと `input` 関数
* **`dollar_to_yen1.py`**: ドルの値から円の値を求める

### 02 モジュールとクラスを活用
* **`lesson202_1-4.py`**: `math` モジュールのインポート
* **`lesson202_6-7.py`**: `sqrt` 関数と `floor` 関数をインポート
* **`lesson202_18-21.py`**: インスタンスとコンストラクタ
* **`lesson202_23-24.py`**: `upper` メソッド
* **`cal1.py`**: 2026年10月のカレンダーを表示
* **`cal2.py`**: `cal1.py` を `calendar` モジュールから `TextCalendar` クラスをインポートして記述

### 03 if文で処理を切り分ける
* **`age1.py`**: 年齢を入力し、if文で成年かどうかを判定
* **`age2.py`**: 年齢を入力し、18歳未満の場合に「未成年です」と表示
* **`age3.py`**: 年齢を入力し、条件式で判定
* **`age4.py`**: 年齢入力時、文字列以外は例外処理
* **`fee1.py`**: 入力した年齢に応じた入場料を表示
* **`test1.py`**: 入力した点数に応じたメッセージを表示
* **`test2.py`**: `test1.py` のif文を入れ子（ネスト）にする

### 04 処理を繰り返す
* **`for1.py`**: 処理を10回繰り返しカウントアップ
* **`for2.py`**: 10から100まで5ずつカウントアップ
* **`reiwa1.py`**: 令和元年から10年までの年を西暦に変換
* **`reiwa2.py`**: `reiwa1.py` を `while` 文で書き換える
* **`reiwa3.py`**: `reiwa2.py` を無限ループと `break` 文を使用して書き換える

### 05 データをまとめて管理するリスト、タプル、辞書
* **`iter1.py`**: リストから要素を取り出して表示
* **`iter2.py`**: 文字列を代入した変数から1文字ずつ表示
* **`comp1.py`**: 文字列を変数に格納し、式を実行して文字列を表示
* **`comp2.py`**: `comp1.py` を内包表記を使って表示
* **`comp3.py`**: 内包表記でリストからリストを生成
* **`comp4.py`**: 拡張子が `.png` の要素のみを取り出してリストを生成
* **`dic1.py`**: `keys` メソッドを使用して辞書「seasons」からキーを順に取り出し、キーと値を表示
* **`dic2.py`**: `dic1.py` を `items` メソッドでキーと値のペアを取得して処理

### 06 ユーザー定義関数を作成
* **`dollar_to_yen2.py`**: ドルから円の金額を求める関数を定義
* **`say_hello1.py`**: 名前と出身地を引数にして文字列を表示
* **`my_sum1.py`**: 任意の数の整数を引数として受け取り、総和を求める
* **`dollar_to_yen3.py`**: 為替レートのデフォルト値を設定してドルから円の金額を求める
* **`dollar_to_yen4.py`**: `dollar_to_yen3.py` をラムダ式で記述

### 07 オリジナルのクラスを作成
* **`doll1.py`**: `Doll` クラスを定義して文字列に出力
* **`doll2.py`**: `doll1.py` を変更してモジュール化し、テスト用ブロックを追加
* **`doll_test.py`**: `doll2` モジュールをインポートして使用
* **`modern_doll.py`**: `Doll` クラスを継承し、新たにさよならの挨拶を追加
