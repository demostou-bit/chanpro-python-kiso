Scrapyのプロジェクトを作成する
----------
scrapy startproject newbooks
----------

newbooks
   |
   |----newbooks
   |           |
   |           |---__init__.py
   |           |---items.py
   |           |---middlewares.py
   |           |---pipelines.py
   |           |---settings.py
   |           |---spiders
   |                  |
   |                  |---__init__.py
   |
   |---scrapy.cfg

basicテンプレートでスパイダーを作成
----------
cd newbooks
----------
続けて入力
----------
scrapy genspider show_newbooks1 book.impress.co.jp
----------
